# Limity darmowych planów

Do uzupełnienia z aktualnej dokumentacji przed etapem 4 (konta) i 5 (multiplayer). Na etapie 1 gra nie korzysta z Supabase, więc żaden limit jej nie dotyczy.

Do sprawdzenia:

- Supabase Realtime: liczba wiadomości na miesiąc, jednoczesne połączenia, wiadomości na sekundę
- Supabase Edge Functions: liczba wywołań na miesiąc
- Supabase: usypianie nieaktywnego projektu, rozmiar bazy, liczba aktywnych użytkowników
- GitHub Pages: rozmiar strony, transfer miesięczny, zasady użycia komercyjnego
